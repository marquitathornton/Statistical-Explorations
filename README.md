# Statistical-Explorations

Overview: 

This repository serves as a personal reference library for Jupyter notebooks containing statistical calculations, methods, and examples. The notebooks are intended to document and organize statistical techniques for future reference, making it easier to revisit calculations, understand methodologies, and reuse code when working on statistical problems.

Contents: 

Descriptive Statistics, Dot Plot, Nice Frequency Table, Visualizations & Tests (Histogram, One Categorical Variable, Two Categorical Variables, One Numeric Variable, Two Numeric Variables, Frequency Tables, Stacked Bar Chart, Testing Correlation Numerically

Purpose:

The primary goal of this repository is to maintain a centralized collection of statistical notebooks that can be used as a reference for learning, problem-solving, and performing statistical calculations.
